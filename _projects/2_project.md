A comparative geospatial analysis of street network structure and OpenStreetMap amenity distribution across 23 cities spanning India and South Korea. Built with OSMnx and Python for network extraction and metrics, and sf/ggplot2 in R for spatial visualization.

The project explores how urban form and amenity accessibility differ across rapidly urbanizing Indian cities and mature, transit-oriented Korean cities, using consistent, reproducible network science metrics for direct cross-country comparison.
